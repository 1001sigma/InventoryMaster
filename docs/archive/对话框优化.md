Context & Objectives

We are adding a Structured Card Interaction Feature into our Android application (InventoryMaster).

Currently, the AI agent returns raw text or tables when querying expired or near-expiry items. We want to intercept the database results of QueryInventoryDataTool and automatically render an interactive Product Card List inside the Jetpack Compose chat stream. Clicking a product on the card will trigger the corresponding UI pop-up window (UiAction).

We follow the Smart Extraction (Layer Separation) approach: The LLM still receives text data to generate its summary, but our ActionResultExtractor and InventoryAiAgent will intercept the raw structured tool result, wrap it into a UiAction, and dispatch it to the Compose UI layer as part of the ChatMessage data model.

🛠️ Step 2: Implementation of Layer Logic

1. Update ActionResultExtractor.kt

We need to parse the database results from QueryInventoryDataTool and convert them into UiAction.ShowProductCardList.

Assume QueryInventoryDataTool returns a JSON Array string containing stock records (with fields like productName, productKey, batchNumber, expiryDate, quantity, sessionId).

// Modify ai/agent/ActionResultExtractor.kt

import com.google.gson.JsonParser
import com.google.gson.JsonArray
import java.text.SimpleDateFormat
import java.util.Date
import java.util.Locale

object ActionResultExtractor {
fun extract(toolName: String, result: String): UiAction? {
// Keep existing extractions...

        // Intercept stock data query results containing specific indicators
        if (toolName == "QueryInventoryDataTool" && (result.contains("expiryDate") || result.contains("stock_records"))) {
            try {
                // Strip the observation wrapper if present
                val jsonStr = if (result.startsWith("Observation:")) {
                    result.substringAfter("\n")
                } else result

                val parsedElement = JsonParser.parseString(jsonStr)
                val jsonArray = when {
                    parsedElement.isJsonArray -> parsedElement.asJsonArray
                    parsedElement.isJsonObject && parsedElement.asJsonObject.has("data") -> {
                        parsedElement.asJsonObject.getAsJsonArray("data")
                    }
                    else -> return null
                }

                val cardProducts = mutableListOf<ExpiredProductCardData>()
                val dateFormatter = SimpleDateFormat("yyyy-MM-dd", Locale.getDefault())

                for (element in jsonArray) {
                    val obj = element.asJsonObject
                    
                    // Safely extract values mapping database fields
                    val productKey = obj.get("productKey")?.asString ?: ""
                    val productName = obj.get("productName")?.asString ?: obj.get("item_name")?.asString ?: "未知医疗器械"
                    val batchNumber = obj.get("batchNumber")?.asString ?: ""
                    val quantity = obj.get("quantity")?.asDouble ?: 0.0
                    val sessionId = obj.get("sessionId")?.asString ?: ""
                    
                    val expiryLong = obj.get("expiryDate")?.asLong ?: 0L
                    val expiryDateStr = if (expiryLong > 0L) dateFormatter.format(Date(expiryLong)) else "未标明"

                    cardProducts.add(
                        ExpiredProductCardData(
                            productKey = productKey,
                            productName = productName,
                            batchNumber = batchNumber,
                            expiryDateStr = expiryDateStr,
                            quantity = quantity,
                            sessionId = sessionId
                        )
                    )
                }

                if (cardProducts.isNotEmpty()) {
                    return UiAction.ShowProductCardList(
                        title = "🔍 系统自动检测到以下关键物资品类：",
                        products = cardProducts
                    )
                }
            } catch (e: Exception) {
                // Fail-safe: if parsing fails, let it fallback gracefully without crashing
                return null
            }
        }
        return null
    }
}

补充的 3 个技术细节

1. 致命隐患：修复 ChatMessageItem 修改后导致的“卡片错位”

在上一轮方案中，我们刚刚在 LazyColumn 渲染层里，将自定义的数据卡片（ProductCardListWidget）紧紧贴在 AI 文本消息的下方：

// 上一轮的设计：
ChatBubbleLayout(message = message) // 这就是你的 ChatMessageItem
message.cardAction?.let { ProductCardListWidget(...) }
隐患分析： 你在本文件的 Task 3 (Step 2) 中，将 !isUser && !isError 的助手消息改为了：
MarkdownText(
text = message.content,
modifier = Modifier.fillMaxWidth() // ⚠️ 这里加了 fillMaxWidth
)
因为你的 ChatMessageItem 通常包含左右气泡的限宽逻辑（例如助手气泡靠左，最大宽度占屏幕 75%）。一旦你在内部直接对 MarkdownText 使用了 Modifier.fillMaxWidth()，它会强行把整个聊天气泡撑满屏幕宽度。这不仅会导致原本精致的左侧气泡变形，还会把下面紧跟的“自定义产品卡片”的边距挤压错位！

补充方案：

让 MarkdownText 顺从外层的容器约束，去掉 fillMaxWidth()。

MarkdownText(
text = message.content,
modifier = modifier // 💡 顺从父组件传进来的宽度约束
)
2. 交互缺失：处理 Markdown 里的链接跳转

大模型在输出 Markdown 时，可能会附带点击链接（例如官方说明链接、甚至是你系统内部的数据超链接 [产品详情](proto://detail/123)）。

multiplatform-markdown-renderer 默认是不拦截点击事件的，如果用户不小心点到了，可能会没反应。

补充方案（在 Task 2 创建 MarkdownText 时加入配置）：

建议在 MarkdownText 里明确让其支持链接高亮或点击处理：

// 修改 Task 2 中的 MarkdownText.kt
Markdown(
markdown = text,
modifier = modifier,
flavour = flavour,
components = markdownComponents(
// 💡 可以在这里定制文字样式，确保长文本在卡片或气泡里有正常的内边距
),
extensions = listOf(tables())
)
3. 性能优化：给 Markdown 渲染加上 remember 缓存

移动端的聊天界面随着滚动（Scroll），LazyColumn 会频繁触发重组（Recomposition）。如果用户和 AI 聊了很久，大模型输出了几千字的盘点报告（包含复杂的表格），每次滚动都会导致 CommonMarkFlavourDescriptor() 重新解析文本，这会导致界面轻微掉帧或卡顿。

补充方案（在 Task 2 中加入 remember 机制）：

@Composable
fun MarkdownText(
text: String,
modifier: Modifier = Modifier
) {
// 💡 缓存解析器，避免滚动列表时重复创建对象导致掉帧
val flavour = androidx.compose.runtime.remember { CommonMarkFlavourDescriptor() }

    Markdown(
        markdown = text,
        modifier = modifier,
        flavour = flavour,
        components = markdownComponents(),
        extensions = androidx.compose.runtime.remember { listOf(tables()) }
    )
}
